# Python Exercises for Practice

Here are some suggested Python exercises to help you sharpen your skills!

## 1. Hangman Game
Create a command-line Hangman game where the computer selects a random word from a list, and the player tries to guess it by suggesting letters.
- **Concepts**: Random module, strings, lists, loops, and conditional logic.

## 2. CLI Task Manager
Build a simple command-line interface (CLI) to manage a to-do list. Users should be able to:
- Add tasks.
- View all tasks.
- Mark a task as completed.
- Remove tasks.
- **Concepts**: Lists, dictionaries, user input, and file handling (optional).

## 3. Contact Book
Implement a contact book application that stores names and phone numbers.
- **Concepts**: Dictionaries, searching, and basic CRUD operations.

## 4. Temperature Converter
Create a script that converts temperatures between Celsius, Fahrenheit, and Kelvin.
- **Concepts**: Mathematical operations, functions, and user input validation.

## 5. Password Generator
Write a script that generates a random password of a given length, including letters (uppercase and lowercase), numbers, and special characters.
- **Concepts**: Random module and strings.

Happy Coding!
