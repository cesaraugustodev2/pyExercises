# Python Learning Exercises

This repository contains a collection of Python scripts and documentation for learning and practicing Python programming. The exercises cover various concepts, including Object-Oriented Programming (OOP), conditional logic, loops, and basic data structures.

## Scripts

- **`class.py`**: Demonstrates basic OOP concepts like classes, inheritance, and data validation using a car example.
- **`jogo_velha.py`**: A simple implementation of the Tic-Tac-Toe game for the command line.
- **`multiplication_table.py`**: A script to generate basic or custom multiplication tables.
- **`sistema_bancario.py`**: A simple banking system simulator with deposit, withdrawal, and statement functionalities.
- **`wallet_book.py`**: Implements `Wallet` and `Book` classes to demonstrate class interactions and state management.

## Documentation

- **`class.md`**: Documentation for the car class examples.
- **`class_docs.md`**: Detailed documentation and specifications for the `Wallet` and `Book` classes.

## How to Run

To run any of the scripts, ensure you have Python 3 installed and execute the following command in your terminal:

```bash
python3 <filename>.py
```

Example:
```bash
python3 multiplication_table.py
```
